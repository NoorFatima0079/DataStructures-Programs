# 📚 Data Structures Programs in Java

A collection of 8 fundamental data structure programs written in **Java** as part of my Data Structures course. Each program is menu-driven or interactive and handles edge cases such as overflow, underflow and invalid positions.

## 👩‍💻 Author
**Noor Fatima** ([@NoorFatima0079](https://github.com/NoorFatima0079))

## 📂 Programs

| # | Program | File | What it does |
|---|---------|------|--------------|
| 1 | 1D Array with While Loop | `OneDArrayWhile.java` | Traverses a 1D array using a `while` loop |
| 2 | Array Operations | `ArrayOperations.java` | Insert, delete, search, update and display |
| 3 | 2D Array | `TwoDArray.java` | Reads a matrix, prints it, finds the sum and the transpose |
| 4 | Stack Operations | `StackOperations.java` | Push, pop, peek and display using an array |
| 5 | Queue Operations | `QueueOperations.java` | Enqueue, dequeue and display using an array |
| 6 | Circular Queue | `CircularQueue.java` | Queue with wrap-around, so freed space is reused |
| 7 | Stack using Linked List | `StackLinkedList.java` | Dynamic stack using nodes |
| 8 | Queue using Linked List | `QueueLinkedList.java` | Dynamic queue using nodes |

## ✨ Features
- Menu-driven programs that are easy to test
- Overflow and underflow handling for stacks and queues
- Circular queue implemented with the modulo (`%`) operator
- Linked list versions using a custom `Node` class
- Clean, commented-style structure, one program per file

## ▶️ How to Run

1. Make sure **Java (JDK)** is installed:
   ```
   java -version
   ```
2. Clone this repository:
   ```
   git clone https://github.com/NoorFatima0079/DataStructures-Programs.git
   cd DataStructures-Programs
   ```
3. Compile and run any program (the file name must match the class name):
   ```
   javac StackOperations.java
   java StackOperations
   ```
